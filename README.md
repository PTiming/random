## 🎯 Project Overview

**Title:** MERN Social Network with Moodle Integration

**Technology Stack:**
- **M**ongoDB - NoSQL database
- **E**xpress.js - Web application framework
- **R**eact - Frontend library
- **N**ode.js - JavaScript runtime

**Key Features:**
- Social networking capabilities (posts, comments, likes, friendships)
- OAuth 2.0 integration with Moodle LMS
- Real-time notifications using Socket.io
- Course-based communities
- Assignment and deadline integration
- Single sign-on authentication

1. Introduction & Problem Statement (3 min)

4. Demo (3 min)
5. Testing & Results (2 min)
6. Challenges & Conclusion (3 min)
